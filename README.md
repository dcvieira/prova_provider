# 🚀 FIAP Tech Wishlist — Prova Prática de Flutter (Provider)

Bem-vindo(a) à avaliação prática de **Gerenciamento de Estado com Provider**!

## 📖 Instruções Rápidas

1. Leia atentamente o arquivo **[`ENUNCIADO_PROVA.md`](./ENUNCIADO_PROVA.md)** na raiz deste projeto.
2. Execute o projeto para visualizar a interface inicial:
   ```bash
   flutter pub get
   flutter run
   ```
3. Procure pelos comentários `// TODO (Questão ...)` nos **5 arquivos da prova**:
   - `lib/providers/wishlist_provider.dart` (**Questão 1 — 3,5 pts**)
   - `lib/main.dart` (**Questão 2 — 1,5 pts**)
   - `lib/widgets/wishlist_badge.dart` (**Questão 3 — 1,5 pts**)
   - `lib/widgets/product_card.dart` (**Questão 4 — 1,5 pts**)
   - `lib/screens/wishlist_screen.dart` (**Questão 5 — 2,0 pts**)
4. Valide sua solução executando os testes automatizados da prova:
   ```bash
   flutter test
   ```
